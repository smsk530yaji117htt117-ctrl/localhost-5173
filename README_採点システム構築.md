# プロセス重視の客観的・定量的採点方法確立ガイド

## 概要

900人分の既存採点データを活用して、**プロセス重視の客観的・定量的採点システム**を確立するための包括的なガイドと実装テンプレートです。

このパッケージは、以下の3つの観点からの提案を含みます：

1. **学術的根拠**（ベストプラクティス）
2. **実装ステップ**（900人データを活用する具体的な方法）
3. **実装例**（即座に使用可能なテンプレート）

## 主な特徴

### 1. 学術的根拠に基づいた設計

- **Wiggins & McTighe (2005)** - Understanding by Design
- **Bloom分類の改訂版** - 認知水準の段階化
- **統計的信頼性手法**
  - ICC (Intraclass Correlation Coefficient): 複数評者の一致度
  - Cronbach's α: 内的一貫性
  - Flesch Reading Ease: 説明の明確性測定

### 2. 900人データの活用方法

```
データ前処理
  ↓
外れ値検出 → 評者バイアス補正 → スコア正規化
  ↓
四分位数からレベル定義（Level 1-4）
  ↓
各レベルの特性分析
  ↓
アンカー例の選定・ガイドライン作成
```

**成果**: 客観的で再現可能な基準値（n=900に基づく）

### 3. 自動化・スケーリング対応

**スライド分析エンジン**:
- Google Slides API を活用
- テキスト密度、見出し統一性、視覚情報バランスを自動計測
- 論理構造を定量化（セクション数、因果関係数）

**音声分析エンジン**:
- Google Cloud Speech-to-Text で文字起こし
- 話速 (wpm)、ポーズ、ピッチ変動を自動計測
- Flesch Reading Ease, 接続詞頻度など言語複雑度を計算

**統合スコアリング**:
```
総合スコア = 0.40×準備構成 + 0.35×実行表現 + 0.15×対話応答 + 0.10×反省改善
  ↓
パーセンタイル計算 → Level 1-4 に自動分類
```

### 4. 即座に実装可能

- Pythonテンプレートはすぐに拡張可能
- JSONスキーマは任意のシステムで使用可能
- チェックリストは実装プロジェクトテンプレートとして機能

## 主要な指標と目標値

### 信頼性指標

| 指標 | 目標値 | 判定基準 |
|------|--------|---------|
| ICC (級内相関係数) | ≥ 0.75 | 複数評者の一致度 |
| Cronbach's α | ≥ 0.80 | 項目間の内的一貫性 |
| 再評価相関 (r) | ≥ 0.80 | 時間的安定性 |
| 分割信頼性 (p) | > 0.05 | グループ間の等価性 |

| Level 3 (十分) | 50-75% | 60-74点 | 223人 |
| Level 2 (発展中) | 25-50% | 45-59点 | 224人 |

## よくある質問 (FAQ)

### Q1: 既存の900人データが不完全な場合は？

**A**: メインガイドの「Phase 1: データの構造化と正規化」を参照。
- 外れ値は除外可能 (標準では0.5%未満)
- 採点者の一部データ欠落は補完推定可能
- 重要: 最小でも400-500人のデータが必要

### Q2: ルーブリックの項目数を変更したい場合は？

**A**: rubric_template.json の構造に従い、以下を修正：
1. `items` 配列に新項目を追加
2. 各項目に `max_points` と4段階レベルを定義
3. `section_weights` を正規化（合計1.0に）
4. メインガイドの「セクション2-2」に従い信頼性を再検証

### Q3: 自動化なしで手入力評価のみの場合は？

**A**: 対応可能。以下の資産が役立つ：
- メインガイド「セクション3.1」のルーブリック評価シート
- rubric_template.json の レベル定義
- IMPLEMENTATION_CHECKLIST の信頼性検証部分

### Q4: 多言語対応したい場合は？

**A**: 
- Flesch Reading Ease は英語専用 → 他言語用の複雑度指標に置き換え
- JSON内のテキストを翻訳
- 音声分析時に言語を指定 (Google Cloud Speech-to-Text対応言語)

### Q5: スコアリング結果の異議申し立てプロセスは？

**A**: メインガイド未記載。推奨プロセス：
1. 自動スコアが信頼閾値外 (±1レベル) → 人間評者が確認
2. 評者が異議 → 別の評者で再評価
3. 複数評者で合意できない → マニュアル判定委員会決議
