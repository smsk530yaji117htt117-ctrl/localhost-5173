# 3. 二段階審査フロー

> 書類審査（客観・定量）→ 役員面接（定性・対話）の連携設計

---

## 3.1 二段階審査の全体像

```
【第一段階】書類審査（7/13〜7/15）
  対象：提出者 全員（約1,000名）
  方法：採点担当者がルーブリックで採点
  結果：スコアによる一次通過者の絞込み（Top 100名）

          ↓ Top 100名に絞込み

【第二段階】役員面接（7/16〜7/17）
  対象：一次通過者（約100名）
  方法：役員2名 × 15〜20分の面接
  結果：最終スコアで順位決定

          ↓ Top 10名を選定

【表彰・動画化】（7/18）
  Top 10名を表彰式で発表・動画上映
```

---

## 3.2 第一段階：書類審査の設計

### 採点担当者の体制

| 項目 | 内容 |
|-----|------|
| 採点担当者数 | 約100名（各部門から選出） |
| 1人の担当件数 | 25〜30件 |
| 採点期間 | 7月13日（土）09:00 〜 7月15日（月）17:00 |
| 1件あたりの採点時間 | 約13分（読込10分 + 記入3分） |
| 採点ツール | Googleスプレッドシート（担当者別シート） |

### 採点の手順

```
Step 1: キャリブレーション（7/13 09:00〜09:30, オンライン）
  └─ サンプル資料3件を全採点者が採点
  └─ 結果を共有し、評価基準のズレを修正
  └─ FAQ対応・不明点解消

Step 2: 独立採点（7/13〜7/15）
  └─ 担当資料（25〜30件）を個別に採点
  └─ ルーブリックシートにスコア＋コメントを入力
  └─ 不明な場合は「保留」マークを付けて進める

Step 3: 集計・確認（7/15 17:00〆）
  └─ 評者3名のスコアを平均化
  └─ 3名の差が20点以上あれば要確認
  └─ 最終スコアでランキング作成
```

### バイアス低減策

```
✓ 部門間クロス採点（自部門の資料は自部門の採点者が担当しない）
✓ 氏名・職位は採点シートに表示しない（可能な範囲でブラインド化）
✓ キャリブレーションによる採点基準の統一
✓ 採点担当者の採点分布を確認（厳しすぎ・甘すぎを検出）
✓ 3名の平均値を使用（1名の極端な採点が全体に影響しない）
```

## 3.3 第二段階：役員面接の設計

### 面接の目的

書類では伝わりにくい以下を評価：
- **人物特性**（誠実さ・情熱・粘り強さ）
- **思考の深さ**（なぜそのプロセスを選んだか）
- **将来性**（これからどう変わろうとしているか）

### 面接の構造（15〜20分）

```
【面接タイムライン】
0:00〜2:00   自己紹介・緊張ほぐし
2:00〜6:00   資料の補足説明（「一番伝えたいことを教えてください」）
6:00〜10:00  プロセス深掘り質問
              └─「その判断をしたとき、他にどんな選択肢がありましたか？」
              └─「最も困難だった瞬間を具体的に教えてください」
10:00〜14:00 組織・会社への貢献質問
              └─「あなたのこの取り組みが会社にどう影響したと思いますか？」
              └─「後輩や同僚に何を伝えたいですか？」
14:00〜15:00 逆質問（面接者への質問）
15:00       終了・お礼
```

### 役員面接の採点項目（50点満点）

| 評価項目 | 配点 | 評価のポイント |
|---------|------|-------------|
| プロセスの言語化力 | 20点 | 自分のプロセスを明確に説明できるか |
| 困難への向き合い方 | 15点 | 困難を避けず、学びに変えているか |
| 組織・会社への視座 | 10点 | 個人を超えた視野があるか |
| 熱量・誠実さ | 5点 | 働くことへの本気度・信頼感 |

### 総合スコア算出

```
最終スコア ＝ 書類審査スコア × 0.5 ＋ 面接スコア × 0.5

例：
  書類審査 85点 × 0.5 ＝ 42.5点
  面接    40点 × 0.5 ＝ 20.0点
  合計               ＝ 62.5点
```

## 3.4 評価の透明性と公平性の確保

### 参加者へのコミュニケーション

```
【事前】
  └─ 評価基準（ルーブリック）を提出要領に明示
  └─ 「プロセス最重視」の理由を丁寧に説明

【事後】
  └─ 参加者全員にサンクスメール（結果に関わらず）
  └─ 希望者にはフィードバック提供（個別メール）
  └─ Top 10名の発表と、選ばれた理由の説明
```

### 異議申し立てプロセス

```
期間：表彰式から2週間以内
方法：人事部への書面申請
対応：採点担当者2名が再採点し、差異が10点以上の場合は審査
```

## 3.5 面接スケジュール管理（Google Calendar 活用）

### スケジュール例（100名 ÷ 2日間）

```
【7月16日（火）】1日 50名
  09:00〜12:00 ── 面接 A会場（役員 A × B）× 10コマ
  13:00〜17:00 ── 面接 B会場（役員 C × D）× 12コマ
  09:00〜17:00 ── 面接 C会場（役員 E × F）× 20コマ
  → 計 42コマ × 20分 ＝ 840分 ÷ 3会場 ≈ 280分/会場

【7月17日（水）】1日 58名
  09:00〜18:00 ── 同様の体制
```

### Google Calendar への反映

```
✓ 各面接を個別イベントとして登録
✓ 面接対象者へ自動招待メール
✓ 会議室をリソースとして予約
✓ 面接官（役員）にも招待送信
✓ 前後5分のバッファをイベントに設定
```
