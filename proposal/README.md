## 🎯 評価の3軸（優先順位）

```
最重要  ①プロセス（50点）
　　　　├─ 仕事の進め方・段取り
　　　　├─ 困難への対処と学習
　　　　└─ 改善・工夫のプロセス

重要　  ②付加価値（30点）
　　　　├─ 業務が生んだ価値
　　　　└─ 組織・顧客・社会への貢献

参考　  ③歴史変容（20点）
　　　　├─ 29年の会社史との接点
　　　　└─ 変化・変革への関与
```

## 🔑 この提案の核心

1. **900人分の過去データを活用** → 採点基準を客観的に導出
2. **定量的なルーブリック** → 評者間のばらつきを最小化
3. **Googleワークスペース活用** → 1,000人規模でも効率的に管理
4. **プロセス最重視** → 単なる結果評価ではなく働き方の変革を促進
