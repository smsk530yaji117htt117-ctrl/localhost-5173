# 5. コミュニケーション戦略＆参加動機づけ

> 任意参加でも、社員が「やってみたい」と感じるイベントにする

---

## 5.1 イベントの「物語」を設計する

### なぜプロセスなのか——伝えるべきメッセージ

単なる評価イベントではなく、**「働き方の変革を起こす場」**として位置づける。

```
【Before（今の文化）】
  └─ 結果だけ見られる → プロセスは自己判断
  └─ 成果を出せばOK → 頑張り方は評価されない

【After（目指す文化）】
  └─ プロセスが評価される → 丁寧な仕事が報われる
  └─ 工夫・改善を語れる場 → ノウハウが社内に広がる
```

### イベントの「一文キャッチコピー」案

```
案①「その仕事に、ロマンはあるか。」
案②「働き方を、語れる社員を増やしたい。」
案③「29年の歴史を、あなたのプロセスで動かす。」
案④「結果じゃなく、なぜ・どうやったかを聞かせてほしい。」
```

## 5.3 リーダー・サブリーダー向けガイダンス

### リーダーの役割

```
リーダーは「採点者」ではなく「伴走者」

× やること：資料の出来を採点する
× やること：書き直しを命令する
○ やること：「もっと聞かせて」と引き出す質問をする
○ やること：「これすごいな」と気づいていない強みを指摘する
○ やること：「こう伝えると伝わりやすいかも」と提案する
```

### チームキックオフで伝えること（7月5日）

```
【キックオフ アジェンダ（60分）】

① イベントの目的確認（10分）
  └─ プロセスを語れる社員を増やすこと
  └─ 評価よりも「自分の仕事を言語化する体験」
  └─ 優秀でなくてもいい、正直に書くことが大事

② 今年のメンバー自己紹介（15分）
  └─ 名前・部門・「今年どんな仕事をしたか一言」

③ スケジュール確認（5分）
  └─ 7/7 ドラフト共有
  └─ 7/10 フィードバック完了
  └─ 7/12 提出

④ 実際にスライド1枚を書いてみる（20分）
  └─「今年一番困ったことは何か？」を1枚に書いてみる
  └─ チームで感想を共有（採点しない、聞くだけ）

⑤ 質疑応答・次回の確認（10分）
```

### フィードバックの黄金ルール

```
良いフィードバックの原則

① 「いいね」から始める（強みを先に）
  ✗ 「このページ、何が言いたいかわからない」
  ✓ 「このエピソードが一番刺さった。もっと詳しく書ける？」

② 「なぜ？」「どうやって？」を聞く
  ✗ 「もっとプロセスを書いて」
  ✓ 「そのとき他にどんな選択肢があったの？なんでそれを選んだの？」

③ 提案は「こうすべき」より「こう見える」
  ✗ 「ここはグラフにしないとダメ」
  ✓ 「ここ数字があると、読む人がイメージしやすそう」

④ 決めるのは本人
  「あとは○○さんの判断で」と締める
```

## 5.4 任意参加の動機づけ設計

### 参加する価値を「3種類」で伝える

```
【価値1: 自分のため】
  └─ 自分の仕事を振り返り、言語化する機会
  └─ 「私はこういう仕事の仕方をしている」という自己理解
  └─ キャリアの棚卸し（転職・異動の際にも使える）

【価値2: チームのため】
  └─ 5〜6名のメンバーと仕事の話ができる希少な機会
  └─ 他のメンバーのプロセスを知ることで自分の視野が広がる
  └─ チームの絆・信頼感の向上

【価値3: 会社のため】
  └─ 優秀な働き方が可視化・共有され、組織全体が学べる
  └─ 29年の歴史と自分の仕事をつなげる体験
  └─ 経営層との直接対話（二次審査）の機会
```

### 非参加者への配慮

```
【非参加者に伝えること】
  └─ 参加強制ではないことを明示
  └─ 表彰式は全社員が見られる動画に（仕事の哲学を学べる機会）
  └─ 来年への期待を温かく伝える
  └─「参加した人のストーリーが社内に広がる」設計
```

## 5.5 イベント成功の指標

### 定量指標

| 指標 | 目標値 | 測定方法 |
|-----|-------|--------|
| 提出率 | 1,000名中 900名以上 | フォーム集計 |
| 提出期限遵守率 | 90%以上 | タイムスタンプ確認 |
| 採点者のスコア一致率（ICC） | 0.75以上 | スプレッドシート計算 |
| 参加者満足度 | 4/5以上 | 事後アンケート |

### 定性指標（事後アンケートで確認）

```
□ 「自分の仕事を振り返るいい機会だった」
□ 「チームメンバーの仕事の仕方を知ることができた」
□ 「プロセスを意識して仕事をするようになった」
□ 「来年も参加したい」
```

### 翌年への継続性

```
├─ 今年の優秀事例を社内ポータルに掲載
├─ 動画を新入社員研修で活用
├─ 翌年の参加者募集時に「去年の受賞者の声」を活用
└─ ルーブリックを毎年見直し・改善
```
