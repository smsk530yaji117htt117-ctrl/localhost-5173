# Googleスライドテンプレート構成案

> 参加者が使うスライドの具体的な構成と、各ページの書き方ガイド

---

## テンプレート仕様

| 項目 | 仕様 |
|-----|------|
| ページ数 | 8〜12ページ（必須8、任意+4） |
| スライドサイズ | 16:9（標準） |
| フォント | 本文 18pt以上、タイトル 24pt以上 |
| カラー | 自由（ただし読みやすさ優先） |
| 1ページのテキスト | 150字以内を目安 |

---

## 各ページの構成と書き方

---

### Page 1: タイトルページ（必須）

```
┌─────────────────────────────────────────┐
│                                           │
│   [仕事のタイトル・キャッチコピー]          │
│                                           │
│   例：「顧客離脱率を半減させた3ヶ月の挑戦」 │
│                                           │
│   氏名：_______________                    │
│   所属：_______________                    │
│   職位：_______________                    │
│   対象期間：2025年 月〜2026年 月             │
│                                           │
└─────────────────────────────────────────┘
```

**書き方のコツ：**
- タイトルは「何をしたか」ではなく「何が起きたか・何を変えたか」で書く
- 例（NG）：「営業活動について」
- 例（OK）：「断られ続けた3ヶ月が変えた、私の提案の仕方」

---

### Page 2: 仕事の全体像（必須）

```
┌─────────────────────────────────────────┐
│  この1年で最もこだわった仕事              │
│                                           │
│  【何の仕事か】                           │
│  ○○プロジェクトの△△担当                  │
│                                           │
│  【なぜこの仕事を選んだか】               │
│  （自分にとってのチャレンジ・意義）        │
│                                           │
│  【一番伝えたいこと（一文）】              │
│  「○○することで△△を実現した体験」        │
│                                           │
└─────────────────────────────────────────┘
```

---

### Page 3〜4: プロセス①「段取り・計画」（必須・最重要）

```
┌─────────────────────────────────────────┐
│  どう準備・計画したか                     │
│                                           │
│  【何を目標にしたか】                     │
│  ・___________________________________    │
│                                           │
│  【どんな段取りをしたか】                 │
│  ・Step1: ________________                │
│  ・Step2: ________________                │
│  ・Step3: ________________                │
│                                           │
│  【工夫したポイント】                     │
│  ←── ここがプロセスのこだわり！          │
│  ・___________________________________    │
│                                           │
└─────────────────────────────────────────┘
```

**書き方のコツ：**
- 「普通にやればいいのに、なぜそのやり方にしたか」を書く
- 「考えた選択肢が複数あって、これを選んだ理由」を書けるとなお良い

---

### Page 5〜6: プロセス②「困難と対処」（必須・最重要）

```
┌─────────────────────────────────────────┐
│  何が一番困難だったか                     │
│                                           │
│  【困難の内容】（具体的に）               │
│  ○月頃、○○という状況が発生。             │
│  ___________________________________      │
│                                           │
│  【なぜ困難だったか】                     │
│  ___________________________________      │
│                                           │
│  【どう対処したか】（自分の判断・行動）   │
│  ①___________________________________    │
│  ②___________________________________    │
│                                           │
│  【そこから何を学んだか】                 │
│  ___________________________________      │
│                                           │
└─────────────────────────────────────────┘
```

**書き方のコツ：**
- 困難は「ハードルが高かった」「大変だった」ではなく、具体的な状況を書く
- 「自分がどう判断したか」が最も評価される部分
- 失敗を書いてもいい。そこからの学びが大切

---

### Page 7: 付加価値・成果（必須）

```
┌─────────────────────────────────────────┐
│  何を生み出したか                         │
│                                           │
│  【数値で見える成果】                     │
│  ・○○率が△%改善（○月→○月）             │
│  ・○○件の新規案件獲得                   │
│  ・○○万円のコスト削減                   │
│                                           │
│  【数値で見えにくい貢献】                 │
│  ・チーム内での○○への波及効果            │
│  ・顧客・社内からのフィードバック         │
│                                           │
│  ↓グラフや写真があればここに挿入↓         │
│                                           │
└─────────────────────────────────────────┘
```

---

### Page 8: 歴史変容（必須）

```
┌─────────────────────────────────────────┐
│  この仕事と会社の29年                     │
│                                           │
│  【会社の歴史との接点】                   │
│  この仕事は、会社が○○してきた歴史の      │
│  ○○という文脈で取り組んでいます。        │
│                                           │
│  【自分が起こした・起こそうとしている変化】│
│  ・組織の中で○○という変化が生まれた      │
│  ・今後○○という方向に変えていきたい      │
│                                           │
│  【次世代への継承・展望】                 │
│  ___________________________________      │
│                                           │
└─────────────────────────────────────────┘
```

**書き方のコツ：**
- 会社の歴史を知らなくても書ける。「自分の仕事が会社の変化にどう貢献したか」でOK
- 難しければ「自分の部門・チームでどんな変化を起こしたか」でも十分

---

### Page 9〜12: 補足資料（任意）

```
使い方の例：
├─ 具体的な数値データ・グラフ
├─ プロセスの詳細図解
├─ プロジェクトのタイムライン
├─ チームの写真・活動記録
└─ 参考資料・引用
```

## 完成チェックリスト

```
□ ページ数は 8〜12ページか？
□ Page 3〜6（プロセス）に全体の半分以上のページを使っているか？
□ 困難のエピソードが具体的か？（「大変だった」ではなく状況が見える）
□ 自分がどう判断・行動したかが書かれているか？
□ 数値・具体例が含まれているか？
□ 1ページのテキストが読みやすい量か？（150字以内目安）
□ タイトルに「何をしたか」だけでなく「何が変わったか」が入っているか？
□ 音声（3〜5分）と内容が対応しているか？
```
