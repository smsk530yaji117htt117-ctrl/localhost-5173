# 採点シート仕様（Googleスプレッドシート）

---

## Sheet 1: 参加者マスタ

| 列 | 列名 | 内容 | 備考 |
|----|------|------|------|
| A | 参加者ID | 001〜1000 | 自動採番 |
| B | 氏名 | — | フォームから自動取込 |
| C | 所属部門 | — | フォームから自動取込 |
| D | 職位 | — | フォームから自動取込 |
| E | 提出日時 | タイムスタンプ | フォームから自動 |
| F | スライドURL | — | フォームから自動取込 |
| G | 音声URL | — | フォームから自動取込 |
| H | 資料確認 | ○/× | 人事チームが手動チェック |
| I | 採点者1 | 氏名 | 割当後に入力 |
| J | 採点者2 | 氏名 | 割当後に入力 |
| K | 採点者3 | 氏名 | 割当後に入力 |
| L | スコア_1 | 0〜100 | 採点者1の合計 |
| M | スコア_2 | 0〜100 | 採点者2の合計 |
| N | スコア_3 | 0〜100 | 採点者3の合計 |
| O | 平均スコア | 自動計算 | `=AVERAGE(L:N)` |
| P | 最大スコア差 | 自動計算 | `=MAX(L:N)-MIN(L:N)` |
| Q | 要確認フラグ | 自動 | 差が20点以上なら"要確認" |
| R | 一次通過 | ○/× | 平均75点以上で通過 |
| S | 面接スコア | 0〜50 | 役員面接後に入力 |
| T | 最終スコア | 自動計算 | `=O*0.5+S*1.0` |
| U | 最終順位 | 自動 | `=RANK(T,T:T,0)` |

### 自動化の数式例

```
Q列（要確認フラグ）:
=IF(P2>=20,"要確認","OK")

R列（一次通過）:
=IF(O2>=75,"○","×")

T列（最終スコア）:
=IF(S2="",O2,O2*0.5+S2)
```

## Sheet 3: 採点担当者シート（個別）

各採点者に個別シートを共有。列構成：

| 列 | 内容 |
|----|------|
| A | 参加者ID |
| B | 氏名（表示するかどうかは検討） |
| C〜K | 各評価項目のスコア（9項目） |
| L | 合計スコア（自動計算） |
| M | コメント（任意） |
| N | 採点完了フラグ |

---

## Sheet 4: 採点進捗管理

| 列 | 内容 |
|----|------|
| A | 採点担当者名 |
| B | 割当件数 |
| C | 完了件数 |
| D | 進捗率（=C/B） |
| E | 最終更新日時 |
| F | ステータス（完了/進行中/未着手） |

### 条件付き書式
- 進捗率 100%: 緑
- 進捗率 50〜99%: 黄
- 進捗率 0〜49%: 赤
